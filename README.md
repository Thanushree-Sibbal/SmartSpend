# SmartSpend 

A full-stack personal finance application that tracks transactions,
manages budgets and savings, provides spending insights, and recommends
nearby places based on your budget.

##  Live Demo

**Frontend:** https://smartspend-mauve.vercel.app/

**Backend:** https://smartspend-dms3.onrender.com

##  Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Vercel
- Render

##  Features

- User authentication
- Transaction management
- Account management
- Budget and savings goals
- Spending insights
- Nearby place recommendations
- Demo UPI account connection
- Secure JWT authentication
